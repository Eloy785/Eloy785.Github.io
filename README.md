# Eloy Perez Quinones — Portfolio

React + Vite portfolio focused on Data Engineering, Data Science, Analytics, Machine Learning, and AI.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## How to keep track of changes

Use small Git commits for each meaningful change:

```bash
git status
git add .
git commit -m "feat: add project window interaction"
git push
```

Suggested commit prefixes:

- `feat:` new feature or section
- `fix:` bug fix
- `style:` visual-only changes
- `content:` resume/project text changes
- `refactor:` code organization changes
- `chore:` setup/dependencies

## GitHub Pages

This repo includes `.github/workflows/deploy.yml`.

In GitHub:
1. Open **Settings → Pages**
2. Set **Source** to **GitHub Actions**
3. Push to `main`
4. The workflow builds `dist/` and deploys it automatically
